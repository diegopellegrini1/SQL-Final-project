# SQL_Final_Project
## 1. Análisis de Base de Datos Sakila mediante SQL 📊💾

## 2. Descripción del Proyecto 📖
Proyecto final del módulo de SQL donde he realizado consultas sobre la base de datos **Sakila**, una base de datos de muestra que simula una tienda de alquiler de películas (DVD rental store).

📊 Objetivo: Resolver más de 60 consultas SQL con el fin de extraer información valiosa de la base de datos, aplicando los conocimientos adquiridos durante el curso.

## 3. Estructura del Proyecto 📝
A continuación, explico la estructura del proyecto realizado, así como los distintos archivos que he utilizado:

**BBDD_Proyecto_shakila_sinuser.sql:**
- Script con el esquema completo de la base de datos Sakila
- Incluye todas las tablas: actor, film, category, customer, rental, payment, inventory, store, staff, address, city, country, language, film_actor, film_category

**queries_sakila.sql:**
- Archivo principal con las 64 consultas SQL que he resuelto
- Cada consulta está numerada y comentada con su enunciado
- Cubren desde consultas básicas hasta análisis más complejos

**EnunciadoDataProject_SQL.Lógica.pdf:**
- Documento con las preguntas y requisitos del proyecto

- README.md: Descripción del proyecto y conclusiones

## 4. Instalación y Requisitos 🛠️
Para realizar este proyecto he utilizado:
- DBeaver --> Para trabajar con las consultas SQL y gestionar la base de datos.
- Visual Studio Code --> Para trabajar con el README.
- Git Hub Desktop --> Para subir mi trabajo final.

## 5. Trabajo Realizado 📊
En el archivo queries_sakila.sql he resuelto 64 consultas SQL que abarcan diferentes niveles de dificultad, desde consultas básicas hasta análisis más complejos con múltiples tablas. He aplicado conocimientos de:
- Consultas básicas con SELECT, WHERE, ORDER BY, LIKE
- Funciones de agregación: COUNT, SUM, AVG, MAX, MIN, VARIANCE, STDDEV
- Relaciones entre tablas usando INNER JOIN, LEFT JOIN, CROSS JOIN
- Subconsultas para análisis más complejos
- Agrupaciones con GROUP BY y filtros con HAVING
- Análisis temporal trabajando con fechas

## 6. Resultados y Conclusiones 📊
He completado con éxito las 64 consultas SQL propuestas en el proyecto, aplicando los conocimientos adquiridos durante el módulo de SQL.

Las consultas resueltas permiten responder preguntas de negocio importantes, como:
- ¿Cuánto dinero ha generado la empresa en total?
- ¿Cuáles son los días con más alquileres?
- ¿Qué categorías de películas tienen mayor duración promedio?
- ¿Qué clientes han alquilado más películas?

El proyecto me ha permitido consolidar mis conocimientos en SQL y entender cómo extraer información valiosa de bases de datos relacionales para la toma de decisiones.
